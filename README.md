# Overview

I developed a console-based Guess the Number Game using Java to strengthen my understanding of programming logic and core Java concepts. The application generates a random number and allows the player to guess it within a limited number of attempts, providing feedback after each guess.

The software demonstrates key Java programming concepts such as variables, loops, conditionals, methods, input handling, and random number generation. It also includes a replay feature, allowing users to restart the game after finishing.

The purpose of building this software was to improve my skills in Java programming, especially in controlling program flow and handling user input effectively. It also helped me practice writing clean, structured, and reusable code.

The project demonstrates my ability to build a functional interactive application using Java syntax and logic.
